# Manzi Studio

Automatic weekly videos for The LLB Guide: Gemini writes exam answers, you approve them by email,
and the cloud makes a long "Topper's notes" video plus Shorts (data drop, myth vs law, quiz, case file,
old vs new law, flowchart) with voice, thumbnails, titles, descriptions, tags, pinned comments and a notes PDF.

- Setup: see **SETUP.md**
- Topics: `topics.csv` · Settings: `config.json`
- Workflows: **1 - Write scripts** (every Sunday 10 pm IST) and **2 - Make videos** (after you approve)
